1. Executive Summary

This document specifies the technical architecture and integration mechanism connecting the fluAi (llm-main) conversational gateway with the Diffy FastMCP (diffy-main) microservice. Designed for enterprise scalability, this architecture solves the two biggest challenges of production AI: high token expenses and sluggish response generation.

Core Strategic Advantages:
  • Sub-Second Roundtrip: Groq Cloud LPU ASIC hardware delivers responses in under 800 milliseconds (5x to 8x faster than traditional cloud GPU infrastructure).
  • 85% Reduction in Token Costs: Eliminates static RAG prompt bloat by calling domain documentation on-demand through standard MCP tools.
  • Zero-Downtime Knowledge Deployments: Real-time synchronization allows domain skills to be added or modified in GitHub without redeploying the backend.
  • Mobile Native Audio Readiness: Capacitor Android client is engineered with secure localhost routing to ensure 100% microphone hardware capture for Whisper speech recognition.

3. How fluAi and Diffy Integrate (Technical Bridge)

The integration between the two systems is completely seamless and autonomous:

A. Zero-Configuration Auto-Discovery

Upon server initialization, fluAi's configuration loader (backend/open_webui/config.py) inspects active tool connections. If the Diffy server connection is absent, it automatically injects https://diffy-ax7l.onrender.com/mcp into the system's runtime connections. No manual configuration in admin panels is ever required.

B. Protocol & Schema Translation

Diffy exposes standard Model Context Protocol tools (list_skills, get_skill, list_skill_files). The mcp_executor.py component intercepts these definitions and compiles them into standard OpenAI function declarations. It utilizes a 4-tier fuzzy name resolution engine to guarantee zero failed function calls.

C. Two-Turn Execution Cycle

When a user asks a question requiring specialized domain knowledge, the Groq LPU issues a tool call. The fluAi gateway pauses user streaming, queries the Diffy FastMCP server via JSON-RPC 2.0, receives the markdown documentation, and injects it back into the model context for turn-2 synthesis—delivering an accurate, hallucination-free answer.

5. Request Lifecycle (Microsecond Packet Trace)

Detailed sequence when a user speaks or submits: "Show me our Flutter Clean Architecture guidelines":

  • [T = 0 ms] User submits prompt via mobile voice or text. Client issues HTTPS POST to /chat/completions.
  • [T = +35 ms] Gateway validates JWT, dynamically binds Diffy tools, and opens upstream stream with Groq Cloud.
  • [T = +190 ms] Groq 120B model evaluates request and emits: delta.tool_calls = [diffy__get_skill('flutter')].
  • [T = +320 ms] Gateway pauses client stream and dispatches JSON-RPC 2.0 request to Diffy FastMCP.
  • [T = +480 ms] Diffy resolves skill://flutter/SKILL.md from local storage (or GitHub fallback) and returns markdown content.
  • [T = +680 ms] Gateway feeds skill payload back into Groq LLM. Model generates final reasoned answer at 520 tok/sec.
  • [T = ~780 ms] Complete, verified Markdown response is rendered on user's screen. Total elapsed: ~780 milliseconds.

7. Security, Privacy & Enterprise Compliance

  • Zero Client-Side Secrets: Sensitive API keys (Groq, Gemini, MCP Bearer tokens) reside solely in server environment variables. Mobile APK and web clients only receive short-lived, signed JWTs.
  • Decoupled Data Isolation: Internal company procedures and documentation remain isolated in Diffy's microservice and are never retained or trained on by external AI models.
  • Cloudflare Anti-Bot Immunity: Upstream requests include full browser-grade signatures to eliminate Cloudflare Error 1010 connection drops.
  • Container Resilience: Memory guards allow both applications to boot in under 4 seconds, even on cost-effective cloud containers.
